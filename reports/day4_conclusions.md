# День 4 — Улучшение baseline: выводы

Все варианты обучались на одном и том же разбиении train/test, сравнение — по macro F1.
Полная таблица: `day4_results.md`.

## Что проверяли

| Способ | Варианты |
|---|---|
| Другие n-граммы | (1,1), (1,3) |
| Другой векторизатор | CountVectorizer, TF-IDF по буквенным n-граммам char_wb (2,5) |
| Другая модель | LinearSVC, ComplementNB, RandomForest |
| Подбор гиперпараметров | GridSearchCV по `C` и `class_weight` (cv=3, scoring=f1_macro) |
| Комбинация | char_wb (2,5) + LogReg с подбором гиперпараметров |

## Что помогло

- **`class_weight='balanced'`** — главный источник прироста (+0.11 к baseline).
  Baseline почти не находил negative из-за дисбаланса классов; балансировка делает
  ошибку на редком классе дороже, и модель перестаёт его игнорировать.
- **ComplementNB** (+0.12) — помог по той же причине: этот вариант наивного Байеса
  создан для несбалансированных данных.
- **Буквенные n-граммы char_wb** (+0.05) — формы одного слова (`profit` / `profits`)
  получают общие признаки, тикеры и числа не теряются.
- **Комбинация char_wb + balanced LogReg** — эффекты сложились: лучший результат.

## Что не помогло

- **N-граммы (1,3)** — без изменений (+0.002, шум): тройки слов редкие и почти не
  попадают в словарь из 5000 признаков.
- **LinearSVC** — небольшой прирост (+0.01, на уровне шума): тоже линейная модель с тем
  же смещением в сторону neutral.
- **RandomForest** — хуже baseline (−0.045): деревьям трудно работать с разреженными
  признаками, где каждый текст содержит пару десятков слов из 5000.
- **Гипотеза про силу регуляризации** не подтвердилась: GridSearch оставил `C=1`.

Неожиданно: **(1,1) лучше (1,2)** (+0.015) — при лимите 5000 признаков частые, но
бесполезные пары слов (`of the`, `in the`) вытесняют из словаря полезные слова.

## Лучший вариант

**TF-IDF char_wb (2,5) + LogisticRegression(C=1, class_weight='balanced')**
Macro F1: **0.6913** (baseline 0.5415, **+0.15 / +27.6%**)

| Класс | Recall: baseline → лучший | F1: baseline → лучший |
|---|---|---|
| negative | 0.12 → 0.64 | 0.17 → 0.55 |
| neutral | 0.89 → 0.76 | 0.78 → 0.78 |
| positive | 0.62 → 0.72 | 0.67 → 0.74 |

**Почему он лучше:** почти весь прирост — за счёт negative: модель находит 64%
негативных новостей вместо 12%. Neutral потерял в recall, но выиграл в precision
(0.69 → 0.81), его F1 не изменился. Accuracy тоже выросла (0.69 → 0.73).

Разницы порядка ±0.01 считаем шумом: в test всего 1167 текстов, из них 172 negative.
